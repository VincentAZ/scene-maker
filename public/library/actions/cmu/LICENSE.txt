Attribution requested by CMU:
The data used in this project was obtained from mocap.cs.cmu.edu.
The database was created with funding from NSF EIA-0196217.

These files were converted from ASF/AMC by Scene Maker. Original 60 or
120 Hz joint samples and timing are retained; files named <trial>_<role>
(for example 113_15_sit) are excerpts that keep only the original samples
inside a stated source interval. Uncaptured finger/thumb channels are
excluded; the visible capsule skeleton is a visualization, not a body scan.
See shared/captured-motion-catalogue.json for source URLs, hashes and mappings.

These files were converted from the dataset's BVH captures (100STYLE.zip,
<style>/<style>_FW.bvh) by Scene Maker: the 60 Hz joint rotations and root
path are kept as recorded, positions are converted from centimetres to
metres, and each file is an excerpt that keeps only the original samples
inside a stated source interval. The capsule skeleton is a visualization.
Changes were made; the original authors do not endorse this product.
